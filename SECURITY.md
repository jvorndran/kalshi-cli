# Security policy

## Supported versions

Security fixes are applied to the latest published version. This project is pre-1.0, so users should upgrade to the newest release before reporting an issue that may already be resolved.

## Reporting a vulnerability

Report suspected vulnerabilities privately through [GitHub Security Advisories](https://github.com/jvorndran/kalshi-cli/security/advisories/new). Do not open a public issue with exploit details, private data, or credentials.

Include the affected version, operating system, Node.js version, reproduction steps, impact, and any suggested mitigation. You should receive an acknowledgment within seven days.

This CLI intentionally has no credential, account, portfolio, order, arbitrary-request, or file-write surface. A report that requires adding Kalshi credentials or calling a non-allowlisted endpoint is outside the supported product boundary.
